# Mi resumen de comandos de Git

git status: me dice qué archivos cambié y cuáles ya preparé.

git add: prepara un archivo para el commit.

git commit: guarda lo preparado en el historial con un mensaje.

git push: sube mis commits a GitHub.

git pull: baja los cambios que otros subieron.

git log: muestra el historial de commits.

git diff: muestra lo que cambié después del add.

git restore: descarta mis cambios y pierdo lo escrito.

git restore --staged: saca el archivo de lo preparado y conserva lo escrito.
